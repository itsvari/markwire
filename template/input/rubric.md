# Example rubric

Replace these examples with the official criteria. Configure matching keys, score maxima, weights, and scopes in `assignment.json`. The workspace cannot prepare a criterion while its scope is `unresolved`.

Each applicable criterion gets a score, student feedback, and evidence. Each evaluation also has an overall remark. See `GRADING_MANUAL.md` for instructions for graders.

## Correctness

- **0** No assessable implementation.
- **1** Major required behaviour is missing.
- **2** The implementation is partial and has important failures.
- **3** Required behaviour works with minor defects.
- **4** Required behaviour and relevant boundary cases work in the documented checks.

## Design

- **0** No assessable implementation.
- **1** Mixed responsibilities make changes hard.
- **2** Some responsibilities are separate, with substantial coupling.
- **3** Responsibilities and interactions are clear.
- **4** The design supports the required changes, and its decisions are well supported.
