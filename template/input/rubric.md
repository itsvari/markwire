# Example rubric

Replace these placeholder criteria with your official marking rubric, then configure matching keys, maximum scores, weights, and scopes in `assignment.json`. Preparation cannot run while any criterion has scope `unresolved`.

Every applicable criterion requires a numerical score, concise student feedback, and concrete evidence, and every evaluation requires an overall remark in `summary`. See `GRADING_MANUAL.md` for detailed marking instructions.

## Correctness

- **0** No assessable implementation.
- **1** Core required behaviour is missing.
- **2** Partial implementation with significant functional failures.
- **3** Required behaviour works with minor defects.
- **4** Required behaviour and relevant boundary cases pass the documented checks.

## Design

- **0** No assessable implementation.
- **1** Tangled responsibilities make changes difficult to reason about.
- **2** Partial separation of responsibilities with substantial coupling.
- **3** Responsibilities and interfaces are clear and maintainable.
- **4** The design cleanly supports required changes and its trade-offs are well justified.
